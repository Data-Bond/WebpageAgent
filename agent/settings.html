全局配置

对所有网页上的插件生效。对话记录、附件与输入框高度仍按当前网站单独保存。
下载
按类别分别下载。点按钮后在弹出框里勾选或导出；配置与记录会生成不同文件，WEB-SKILL 为 JSON。
重载
选择 JSON 文件载入。配置文件中没有的字段保持现状；密钥为 ******** 时沿用本机已有值。WEB-SKILL 同 id 会作为新条目导入。
诊断记录
记录功能探针（含成功路径的活动轨迹）与错误类，不含 API 密钥、提示词、页面内容或附件。保留最近 24 小时，并受上限约束。下载诊断数据请用上方「下载」里的「下载其他数据」。
默认 50KB，可填 10–200。改后请点页面底部「保存」。超出上限时丢掉最旧记录。
插件界面
数值越小越透明，可透过面板看到网页。按钮与文字保持清晰。
标题栏缩放按钮会把面板放到当前网页可视区域的该比例。附件与发送按钮保持原像素大小。
运行参数（全局）
PDF 解析范围
「-1」表示最后一页。默认 1,2,3,-2,-1；正数与负数若指向同一页，只解析一次、不重复 OCR。
解析全部页会对每一页做文本提取，无文本层的页会渲染后 OCR，大文件可能较慢。
只计量本地 PDFium 从当前这份 PDF 抽出的文本层字符数（含页分隔与空白），不是发给大模型的整段提示词，也不是多附件合计或对话历史。达到上限后，尚未扫描的所选页不再抽文本、也不再 OCR。
OCR 的 providerType 为 MinerU 时，始终把整份 PDF 交给 MinerU 做 OCR：不受上方页码配置约束，也不受「PDF 文本层上限」约束。本地 PDFium（文本层抽取与按页渲染 OCR）仍同时受这两项约束。
附件正文预算
按站点（网页 origin）分别计，缓存的是该站已抽出的 PDF/图片正文合计，用来免重复 OCR。不是发给模型的提示词，也不是单份附件上限，更不是「PDF 文本层上限」。默认 50 万，可填 5 万–200 万。只需管总字数；条数最多 50 条，超出总字数或条数时按写入先后丢掉最旧条目。
一次发给文本模型的多附件正文合计，不是 PDF 文本层、不是 OCR 缓存、也不是整段系统提示词或对话历史。默认 15 万，可填 1 万–50 万。超出会截断并标注。
存档脱敏指令
保存对话时可用这段话作为发给文本模型的用户脱敏指令。此处改的是默认文案；每次保存仍可再改，并可多次迭代脱敏。
文本模型 System Prompt
每次调用文本模型时置于上下文最前。
文本模型 Providers（类型仅 OpenAI-chat-completions：OpenAI 兼容 /chat/completions，Base URL / 模型ID 自行填写）
OCR 模型 System Prompt
视觉模型调用时置于最前。OCR-SCnet / MinerU 不使用这段提示词。
OCR Providers（类型必选：OpenAI-chat-completions-image_url 为视觉 chat；OCR-SCnet 为 multipart；MinerU 为文档解析）
